# Шаблон домашнего задания

Новое ДЗ: **Use this template** → назвать репозиторий по коду урока (например, `VPf04`) → вставить задание в `TASK.md` → открыть облачную сессию Claude Code и приложить PDF урока.

| Файл | Зачем |
|---|---|
| `CLAUDE.md` | Правила для Claude Code: разбор урока, работа, итог сессии |
| `TASK.md` | Текст задания из урока |
| `NOTES.md` | Разбор, чек-лист статусов, команды для локального запуска |
| `.env.example` | Какие переменные нужны; сам `.env` в git не попадает |

Этот README заменяется описанием проекта, когда ДЗ готово.

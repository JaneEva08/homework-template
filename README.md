# Шаблон домашнего задания

Новое ДЗ: **Use this template** → назвать репозиторий по коду урока (например, `VPf04`) → вставить задание в `TASK.md` → открыть облачную сессию Claude Code, приложить PDF урока и написать `/dz`.

После `/dz` можно добавить уточнение: `/dz взять за основу https://github.com/JaneEva08/fotochka` или `/dz делаем средний уровень`.

| Файл | Зачем |
|---|---|
| `CLAUDE.md` | Контекст и правила для Claude Code: обо мне, стек, проекты, этапы |
| `.claude/skills/dz/` | Навык `/dz`: найти PDF, разобрать урок, сделать черновой этап |
| `TASK.md` | Текст задания из урока |
| `NOTES.md` | Разбор, чек-лист статусов, команды для локального запуска |
| `.env.example` | Какие переменные нужны; сам `.env` в git не попадает |

Этот README заменяется описанием проекта, когда ДЗ готово.
